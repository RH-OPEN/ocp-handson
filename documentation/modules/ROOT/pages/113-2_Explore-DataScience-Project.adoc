== DataScience Project

DataScience Projectには以下が含まれます。

* *Workbenches:*
マシーンラーニング、データサイエンスのための開発環境

* *Pipelines:*
マシーンラーニング、データサイエンスのためのパイプラインを設定

* *Deployments:*
モデルランタイムとモデルのデプロイの設定

* *Cluster storage:*
Workbenchで中間ファイルなどの共有情報を保持するために使用する、永続ボリュームの設定

* *Connections:*
モデルなどを保存じたりするためのオブジェクトストレージへのアクセス情報（実態は OpenShift の Secret）

* *Permissions:*
アクセス件を設定

* *Settings:*
プロジェクトの設定

== モデルのランタイムの作成とモデルのデプロイ

Deployments タブから、#Deploy model# を選択します。

image::rhoai3/project/deploymentstab.png[link=self, window=blank, width=100%]

*Model location* に #Existing connection# 、を *Model type* に #Generative AI model (Example, LLM)# 選択（*Connection* は1つしか存在しないので自動で選択されます。）し、#Next# を選択します。

image::rhoai3/project/modeldetails.png[link=self, window=blank, width=100%]

*Model deployment name* を llama-32-3b-instruct
とし、*Hardware profie* に #gpu-profile# を選択します。

image::rhoai3/project/modeldeployment.png[link=self, window=blank, width=100%]

[blue]#Customize resource request and limits# を開いて以下を設定します。

* *CPU requests :* 1 Cores
* *CPU limits :* 4 Cores
* *Memory requests :* 6 GiB
* *Memory limits :* 16 GiB
* *GPU requests :* 1
* *GPU limits :* 1

image::rhoai3/project/customizeresource.png[link=self, window=blank, width=100%]

*Service runtime* は #Auto-select the best runtime for my model based on model type, model format, and hardware profile# にして、#Next# を選択します。

image::rhoai3/project/servingruntime.png[link=self, window=blank, width=100%]

*Model playground availability* の *Add as AI asset endopoint* と *Configure parameters* の *Add custom runtime arguments* をチェックします。

image::rhoai3/project/advancedsettings.png[link=self, window=blank, width=100%]

パラメーターに以下を入力して、*Next* を選択します。

[.console-input]
[source]
----
--dtype=half
--max-model-len=20000
--gpu-memory-utilization=0.95
--enable-auto-tool-choice
--tool-call-parser=llama3_json
--chat-template=/opt/app-root/template/tool_chat_template_llama3.2_json.jinja
----

image::rhoai3/project/runtimearguments.png[link=self, window=blank, width=100%]

Review 画面で入力を確認して、#Deploy model# を選択します。

image::rhoai3/project/deploymodel.png[link=self, window=blank, width=100%]

Deploy中：
image::rhoai3/project/deploying.png[link=self, window=blank, width=100%]

Deploy 完了後：
image::rhoai3/project/deployed.png[link=self, window=blank, width=100%]
